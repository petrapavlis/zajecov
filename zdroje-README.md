# Primární podklady

Archiv dokumentů, ze kterých studie vychází. Důvod, proč jsou tady:
úřední desky obcí dokumenty po čase snímají a odkazy přestanou fungovat.
Ověřitelnost tvrzení by tím zanikla.

| Soubor | Původ | Co z něj studie bere |
|---|---|---|
| `up-zajecov-2019-uplne-zneni.pdf` | zajecov.cz/uzemni-plan | Koncepce rozvoje, plochy občanského vybavení, zásobování vodou, zákaz komerčních FVE, veřejně prospěšná opatření vodního režimu |
| `strategicky-plan-2017-2026.pdf` | zajecov.cz | SWOT analýza, obecní lesy, kamenolom, plán záměrů, stav úvěrů v roce 2016 |
| `spu-kopu-zajecov-v-brdech-2025.pdf` | úřední deska obce | Rozhodnutí o schválení návrhu, věta o prázdném plánu společných zařízení |
| `spu-kopu-zajecov-kvan-2024.pdf` | úřední deska obce | Zpracovatel AGROPLAN, termín prací 2024–2027 |
| `monitor-*.pdf` | monitor.statnipokladna.gov.cz | Dluh, dluhová služba, rozpočtová odpovědnost, přehled transferů |

## Jak doplnit další

Stáhněte dokument, pojmenujte ho podle vzoru výše, přidejte řádek do
tabulky a pošlete pull request. Nebo pošlete odkaz v issue a doplním to.
